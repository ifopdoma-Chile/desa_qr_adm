Webhooks de escaneo

Los webhooks reciben un POST con JSON por cada escaneo de un QR. Ideal para integrar el sistema con dashboards, Telegram, planillas o cualquier servicio que exponga una URL. Ejemplo del payload: 

{
  "event": "scan",
  "qr":   { "id": 1, "slug": "abc123", "title": "Mi QR", "url": "https://..." },
  "scan": { "id": 42, "scanned_at": "2026-08-07T14:00:00+00:00", "ip": "1.2.3.4",
            "device": "mobile", "browser": "Chrome", "os": "Android",
            "country": "Chile", "city": "Valparaiso",
            "latitude": -33.04, "longitude": -71.62 }
}
